# AZAEL — HERDEIRO DO CAOS

Projeto independente de RPG 3D em terceira pessoa, desenvolvido em Godot 4.7 ou posterior (recomendado).

## Direção do projeto

- Fantasia anime estilizada em 3D.
- Android como plataforma prioritária.
- Exploração, combate em tempo real, missões e decisões narrativas com consequências.
- Qualidade gráfica escalável para aparelhos de diferentes capacidades.
